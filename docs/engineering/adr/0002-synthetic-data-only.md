# ADR 0002: Synthetic data only

- **Status:** Accepted
- **Date:** 2026-11 (GCP-01)
- **Deciders:** repository owner

## Context

A finance assistant touches payer accounts, IBANs and amounts. A learning landscape on a personal cloud project must not hold anything real.

## Options considered

A) Anonymised real data. B) Synthetic data generated by the scenario and the seeds.

## Decision

B. Every account, order, payment and customer is generated; the SECURITY.md states it; masking rules (IBAN, card, e-mail, US phone and account) exist anyway, so the behaviour is demonstrated.

## Consequences

No data-protection exposure. The cost is that data realism is limited (repeated amounts across runs caused ambiguity cases, ADR 0019); masking is proven against patterns, not against real leakage.
